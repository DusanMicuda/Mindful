# Flutter Tooling and CI

## Toolchain and setup

- No Flutter SDK pin. `pubspec.yaml` allows Dart `>=3.1.0 <4.0.0`; `pubspec.lock` records resolved SDK floors Dart `>=3.8.0` and Flutter `>=3.31.0-0.0.pre`. CI installs Flutter with `subosito/flutter-action@v2` without a pinned version.
- Android uses Java/JVM 17, AGP 8.10.1, Kotlin 1.8.22, and Gradle wrapper 8.14.2 (`android/settings.gradle`, `android/app/build.gradle`, `android/gradle/wrapper/gradle-wrapper.properties`).
- Follow `README.md` and `docs/CONTRIBUTING.md` for setup and builds. From the repo root:

```sh
flutter pub get
dart run build_runner build -d
flutter analyze
dart format .
flutter build apk
```

Run generation only when Drift/code-generation inputs change. For ARB edits, run `flutter gen-l10n` (also generated by Flutter builds because `pubspec.yaml` has `generate: true`).

## CI

GitHub Actions workflows are under `.github/workflows/`:

- `build_and_deploy.yml` builds and deploys an Android app bundle to Play Store on `v*` tags; it sets up JDK 17 and Flutter.
- `download_translations_from_crowdin.yml` downloads translations and opens a GitHub pull request.
- `upload_sources_to_crowdin.yml` uploads localization sources.

These workflows do not define a general test/analyze gate. Run the relevant local checks and report exact commands/results; do not claim CI ran checks it does not contain.

## Generation and Android

- Drift uses `dart run build_runner build -d`; review generated changes with the table/model edits.
- Localization uses Flutter gen-l10n and ARB files; do not hand-edit generated localization output.
- Android Gradle files use Groovy DSL. Keep native changes in `android/` and verify with `flutter build apk --debug` when relevant.
- Match versions to the repo's pubspec, lockfile, Gradle wrapper, and workflow configuration; do not invent pinned tool versions or setup scripts.

## Before review

- Run `flutter analyze` and `dart format .`.
- Run affected tests/builds and report unavailable device/platform checks.
- Inspect `git diff --check` and the complete diff for generated or lockfile churn and unrelated files.
